## 4. Test Procedure

For each test case:

1. Open the SolarGuard AI application.
2. Enter the technician query.
3. Click the Ask Assistant button.
4. Observe the response.
5. Compare the response with the expected result.
6. Record the actual response category.
7. Mark the test as Pass or Fail.

---

## 5. Testing Criteria

A test case is considered successful when:

- The assistant responds to the technician query.
- The appropriate maintenance category is identified.
- Relevant maintenance steps are provided.
- Safety considerations are included when required.
- Electrical issues are appropriately escalated when required.
